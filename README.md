# Launch — HumStack.in

> Technology & Digital Growth Studio. **Build. Launch. Grow.**

Production-quality marketing website and web application for [HumStack.in](https://humstack.in).

## Tech Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- React Router DOM

## Getting Started
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
npm run preview
```
